# Profile Card

Um cartão de perfil pessoal desenvolvido com HTML5 e CSS3, com foco em semântica, acessibilidade, responsividade e design de interface.

## 🎯 Sobre o projeto

Este projeto consiste em um cartão de perfil desenvolvido para apresentar informações pessoais e profissionais de forma simples, moderna e visualmente organizada.

A interface apresenta meu perfil, área de interesse, localização e conhecimentos relacionados ao desenvolvimento Front-end e UX/UI Design.

O projeto foi desenvolvido como parte do meu processo de aprendizado em desenvolvimento web e busca colocar em prática conceitos de HTML e CSS.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## 📚 Conceitos praticados

### HTML

- Estrutura semântica
- Elementos `header`, `main`, `section` e `figure`
- Hierarquia de títulos
- Atributos de acessibilidade
- Texto alternativo em imagens
- Meta tags

### CSS

- Flexbox
- Variáveis CSS (`:root`)
- Responsividade
- Media Queries
- `clamp()`
- Transições
- Efeitos de `hover`
- Gradientes
- Sombras
- Bordas arredondadas
- Organização e reutilização de estilos

## ♿ Acessibilidade

O projeto utiliza alguns recursos para melhorar a acessibilidade, como:

- Texto alternativo na imagem de perfil
- Estrutura semântica em HTML
- Hierarquia adequada de títulos
- Atributos `aria-labelledby` para relacionar seções e seus títulos

## 📱 Responsividade

O cartão foi desenvolvido para se adaptar a diferentes tamanhos de tela.

Foi utilizada uma Media Query para ajustar o espaçamento, tamanho da imagem e organização do cabeçalho em dispositivos menores.

## 🎨 Design

A interface utiliza:

- Fundo com gradiente
- Cartão com bordas arredondadas
- Sombras suaves
- Paleta de cores clara
- Tipografia utilizando DM Sans e Space Grotesk
- Etiquetas visuais para representar interesses e conhecimentos

O cartão também possui uma animação de `hover`, fazendo com que ele se eleve levemente quando o usuário passa o mouse sobre a interface.
